# Dual Webcam Portrait Tester

A browser-based testing page for two webcams.

## Features

- Detects available browser webcams.
- Shows Camera A and Camera B side by side in 6:19 portrait viewfinders.
- Lets each viewfinder rotate to 0, 90, 180, or 270 degrees.
- Lets each viewfinder switch between mirror and no-mirror output.
- Exchanges the assigned devices between Camera A and Camera B.
- Captures Camera A as a portrait photo.
- Records Camera B as a 5-second portrait video.
- Shows the captured photo and video on a result screen.

## Local Use

```bash
npm install
npm run dev
```

Open the local address printed by the development server and allow camera access
when the browser asks.
